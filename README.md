# Student Profile

A responsive one-page student profile website created with HTML and CSS.

## Included files

- `index.html` — the complete profile page
- `style.css` — responsive styling for the page

## Features added for Practical Question 2

- Skills section
- Education section
- Contact information
- Improved responsive design for desktop and mobile screens

## Run locally

Open `index.html` in any web browser.

## Git and GitHub submission commands

Run these commands from inside the `Student-Profile` folder. Replace `YOUR-USERNAME` with your GitHub username.

```bash
git init
git add .
git commit -m "Create student profile website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Student-Profile.git
git push -u origin main
```

After editing the website for Practical Question 2, use:

```bash
git status
git add index.html style.css
git commit -m "Add profile details and improve design"
git push
```

Create an empty public repository named `Student-Profile` on GitHub before running the first set of commands. Then copy the repository URL from your browser and share it with your instructor.
